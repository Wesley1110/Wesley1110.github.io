不要以為做 DID 就可以解決內生性問題

以 Heese, Pérez-Cavazos, and Peter（2022）為例。

Teaching note · Chinese

DID 仍然可能有內生性問題

公司理財實證研究中，會很常用到 DID 的方法。但值得注意的是，不要以為做 DID 就可以解決內生性問題。DID 只是在某些假設成立時，可以把處理組與控制組原本固定不變的差異消掉；但如果處理事件本身不是外生的，或處理組與控制組在事件前後本來就會走不同趨勢，DID 還是會有內生性問題。

內生性（Endogeneity）問題有三大來源，分別是遺漏變數（Omitted Variables）、測量誤差（measurement error）與雙向因果（simultaneity bias）。以下用地方報紙倒閉與企業違規的例子，說明為什麼跑完 DID 之後，因果關係仍然可能受到質疑。

地方報紙倒閉與企業違規

我們以 Heese, Pérez-Cavazos, and Peter（2022）發表在 Journal of Financial Economics的論文為例。作者研究地方報紙倒閉是否會使當地企業違規增加。DID 的實證結果發現，地方報紙倒閉後，當地上市公司廠房的違規與罰款增加。

然而，不要以為做 DID 就可以解決內生性問題，因為報紙倒閉本身可能不是隨機的。地方報紙倒閉可能不只是因為報業衰退，也可能是地方經濟惡化所造成。假設某個 county 的經濟開始衰退，地方廣告收入下降，導致地方報紙倒閉；同一時間，經濟惡化也可能讓企業壓力變大，進而更容易違規、偷工減料，或違反勞動與環保規定。

DID 可能被解讀成：Newspaper Closure → Corporate Misconduct

如果只仰賴 DID，看到報紙倒閉後企業違規增加，就會以為因果關係是 Newspaper Closure → Corporate Misconduct；但背後共同的原因可能是 Local Economic Decline。這就是 omitted variable bias。

因此，審稿人或讀者自然會問：怎麼知道是報紙倒閉造成企業違規增加？會不會是那些地方本來就在變差，所以報紙倒閉和企業違規增加同時發生？

進一步來說，也可能有雙向因果問題。某個地方的企業與地方政客勾結極為嚴重，甚至聯手透過法律訴訟或抽走廣告，硬生生把一家天天爆料的正義報社逼到破產。如果是這樣，就是企業先有嚴重的違規與腐敗，才導致報紙倒閉，因果關係完全相反倒置了。

用 Craigslist 作為工具變數

那麼該如何解決這個內生性問題？當自變量 X（報紙倒閉）與殘差項（包含地方經濟衰退等不可觀測因素）糾纏不清時，就需要引入一個乾淨的第三方變數，也就是工具變數 Z（Craigslist 的擴張）。一個合格的工具變數必須同時滿足兩大 Conditions：

1. 相關性（Relevance）

工具變數 Z 必須與自變量 X 強烈相關。Craigslist 是美國早期的分類廣告巨頭。過去地方報紙有很大一部分收入來自分類廣告，例如徵人、租屋與二手車買賣。Craigslist 進入某個城市，直接斷了地方報紙的財路，大大加速了報紙倒閉。

2. 外生性（Exogeneity）

工具變數 Z 只能透過影響 X 來影響應變量 Y（企業違規）。Craigslist 的進入不能與地方經濟衰退等隱藏的干擾因素有關，也不能直接影響 Y。Craigslist 決定何時進入哪一個城市，主要是看當地的網際網路基礎建設與它在全美擴張的時間表。Craigslist 的總部不會知道某個城鎮的化工廠是否準備在下個月偷排廢水。因此，Craigslist 的進入對當地企業而言，可以被視為一個外生衝擊（exogenous shock）。

當然，Exogeneity 不能只靠這段直覺就成立。研究者仍然需要說明 Craigslist 的進入時點，並提供進一步的 evidence 支持 exclusion restriction。

DID 是 identification strategy，不是萬靈丹

總而言之，DID 是一種 identification strategy，但不是內生性的萬靈丹。做完 DID 之後，仍然要面對處理事件是否外生、parallel trends 是否合理，以及是否存在 omitted variables 或雙向因果等問題。

這篇論文再使用 Craigslist 作為 IV，是為了回應 Newspaper Closure 可能不是隨機事件的質疑。不過，並不是每篇 DID paper 都一定要再補一組 IV regression。是否需要 IV，取決於研究面對的是哪一種 endogeneity problem，以及是否真的找得到 valid instrument。若工具變數本身不可信，硬加一組 IV regression 並不會讓論文更嚴謹。

欲尋找 IV，請尋找 VI

頂尖學者通常可以自己提出有趣的工具變數，但若無法自創工具變數，而這通常才是一般研究者會遇到的情況，那該怎麼辦？

藉由唐代杜牧的《清明》：

清明時節雨紛紛，路上行人欲斷魂。
借問酒家何處有，牧童遙指杏花村。

研究者想找工具變數，就像詩中的行人想找酒家一樣。你知道自己需要它，但不一定知道它在哪裡。最後往往要靠別人指路，也就是靠過去文獻、制度背景、歷史事件、自然實驗或政策變動，幫你找到可能的 IV。

杏花村指的就是 Valid Instrument（VI）。也就是說，欲尋找 IV，請先尋找 VI。

Reference

Heese, J., Pérez-Cavazos, G., & Peter, C. D. (2022). “When the Local Newspaper Leaves Town: The Effects of Local Newspaper Closures on Corporate Misconduct.” Journal of Financial Economics, 145(2), 445–463.
